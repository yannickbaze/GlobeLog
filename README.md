🌍 GlobeLog
GlobeLog is a React application that helps users keep track of the cities they've visited around the world. Users can explore an interactive map, save memorable locations, and build their own personal travel journal.



✨ Features
🗺️ Interactive world map

📍 Add cities by clicking on the map

📝 Save notes about each location

🗂️ View all visited cities

🌍 Browse visited countries

⚡ Fast navigation with React Router

🔄 Context API for global state management

📱 Responsive design

Installation
Clone the repository:

git clone https://github.com/yannickbaze/globelog.git
Navigate to the project folder:

cd globe-log
Install dependencies:

npm install
Start the mock API:

npm run server
In another terminal, start the development server:

npm run dev
Open your browser at:

http://localhost:5173
